# ☕ Beck's Coffee Showcase

**Beck's Coffee Showcase** é uma *landing page* moderna, responsiva e sofisticada criada para apresentar o **Beck's Café**, destacando cafés especiais, acompanhamentos e a experiência única da cafeteria.

🚀 **Live Demo:** [becks-coffee-showcase.lovable.app](https://becks-coffee-showcase.lovable.app)

---

## 📌 Sobre o Projeto

O objetivo do projeto é oferecer um espaço digital receptivo e visualmente atraente para os clientes do café, integrando design moderno a uma navegação fluida.

### Key Features
* ☕ **Menu de Bebidas & Cafés:** Apresentação detalhada de grãos especiais, métodos de extração e bebidas da casa.
* 🥐 **Acompanhamentos:** Vitrine de doces, salgados e opções para harmonização.
* 🎨 **Design Sofisticado:** Interface responsiva construída com componentes elegantes e animações suaves.
* 📍 **Informações de Contato e Horários:** Seção dedicada à localização, horários de funcionamento e redes sociais.

---

## 🛠️ Tecnologias Utilizadas

* **Front-end:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **Componentes:** [shadcn/ui](https://ui.shadcn.com/)
* **Plataforma de Desenvolvimento:** [Lovable](https://lovable.dev/)

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
Certifique-se de ter o **Node.js** (versão 18+) e o **npm** ou **bun** instalados em sua máquina.

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/ferbeckman27/becks-coffee-showcase.git](https://github.com/ferbeckman27/becks-coffee-showcase.git)
Acesse o diretório do projeto:

Bash
cd becks-coffee-showcase
Instale as dependências:

Bash
npm install
# ou
bun install
Inicie o servidor de desenvolvimento:

Bash
npm run dev
# ou
bun dev
Abra o navegador e acesse http://localhost:5173.
